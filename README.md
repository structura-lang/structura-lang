# Structura

Structura is a structured-data programming language designed around JSON-compatible data, expressions, operations, and functions.

The language specification is the authoritative reference for the language and its syntax.

## Documentation

See [`spec.md`](spec.md) for the complete Structura language specification.

## Implementations

### Official Go Implementation

The official Go implementation of Structura is available at:

[github.com/structura-lang/structura-go](https://github.com/structura-lang/structura-go)

### Test Suite

The official Structura test suite is available at:

[github.com/structura-lang/structura-tests](https://github.com/structura-lang/structura-tests)

The test suite is intended to verify implementations against the language specification.
